一、项目总览

这是一个 Java 原生 Android 应用，包名是 com.example.jntt。启动页是 LoginActivity，登录后进入 MainActivity，主界面用三个 Fragment 承载“头条、商城、我的”。

界面层
Activity / Fragment / XML layout
负责展示页面、监听按钮点击、跳转页面。
列表适配层
adapter/*.java
负责 RecyclerView 每一行如何显示、勾选、点赞、加减数量。
数据层
DataManager.java
所有业务数据读写入口，封装 SQLite SQL 与 SharedPreferences。
数据库层
AppDatabase.java
创建本地 SQLite 数据库 jntt.db 和业务表。

核心结论：当前项目没有连接远程后端、MySQL 或 REST API。所有用户、文章、商品、购物车、订单、点赞、评论、关注、商品评价都保存在手机本地 SQLite 数据库 jntt.db；登录态与管理员开关保存在本地 SharedPreferences。

用户做了什么：在注册页输入用户名、密码、手机号，点击注册。

第一段：RegisterActivity 收集输入并做格式校验。这段代码放在 Activity 中，因为它处理的是“界面输入是否合法”，比如输入框空不空、手机号格式对不对。校验放在写数据库之前，可以避免无效数据进入数据库。

代码位置：app/src/main/java/com/example/jntt/RegisterActivity.java，第 53-74 行
private void doRegister() {
    String username = etUsername.getText().toString().trim();
    String password = etPassword.getText().toString().trim();
    String phone = etPhone.getText().toString().trim();

    if (username.isEmpty() || password.isEmpty()) {
        Toast.makeText(this, "用户名和密码不能为空", Toast.LENGTH_SHORT).show();
        return;
    }
    if (!username.matches("^[a-zA-Z0-9\\-@_.]+$")) {
        Toast.makeText(this, "用户名只能包含字母、数字及-@_.", Toast.LENGTH_SHORT).show();
        return;
    }
    if (password.length() < 6) {
        Toast.makeText(this, "密码至少6位", Toast.LENGTH_SHORT).show();
        return;
    }
    if (!phone.isEmpty()) {
        if (phone.length() != 11 || !phone.matches("^1[3-9]\\d{9}$") || phone.matches("^(\\d)\\1{10}$")) {
            Toast.makeText(this, "请输入有效的11位手机号", Toast.LENGTH_SHORT).show();
            return;
        }
        if (dm.isPhoneBound(phone)) {
            Toast.makeText(this, "该手机号已被注册或绑定，请更换手机号", Toast.LENGTH_SHORT).show();
            return;
        }
    }

    boolean ok = dm.register(username, password, phone);
    if (!ok) {
        Toast.makeText(this, "该用户名已被使用，请更换用户名", Toast.LENGTH_SHORT).show();
        return;
    }
    Toast.makeText(this, "注册成功", Toast.LENGTH_SHORT).show();

    if (isAddMode) {
        finish();
    } else {
        dm.setLoggedUser(username);
        Intent intent = new Intent(this, MainActivity.class);
        intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
        startActivity(intent);
    }
}

为什么这样做：trim() 去掉首尾空格，防止用户不小心输入空格导致账号难以识别；return 让每次发现错误立刻停止；isAddMode 让同一个注册页面复用成“添加账号”页面。

第二段：DataManager 判断手机号唯一并写入 users 表。真正的注册写库不放在 Activity，而放在 DataManager，是因为所有数据操作集中在一个类里，后续别的页面也能复用。

代码位置：app/src/main/java/com/example/jntt/data/DataManager.java，第 99-112 行
public boolean register(String username, String password, String phone) {
    if (phone != null && !phone.isEmpty()) {
        if (isPhoneBound(phone))
            return false;
    }
    ContentValues cv = new ContentValues();
    cv.put("username", username);
    cv.put("password", password);
    cv.put("nickname", username);
    if (phone != null && !phone.isEmpty()) {
        cv.put("phone", phone);
    }
    return wdb().insertWithOnConflict("users", null, cv, SQLiteDatabase.CONFLICT_IGNORE) != -1;
}

为什么这样做：ContentValues 是 Android SQLite 推荐的键值写入方式；insertWithOnConflict(..., CONFLICT_IGNORE) 利用数据库唯一约束处理重复用户名，不需要手写复杂判断；默认 nickname=username 是为了个人中心没有昵称时也能显示名称。

代码位置：app/src/main/java/com/example/jntt/data/DataManager.java，第 118-122 行
public boolean isPhoneBound(String phone) {
    try (Cursor c = rdb().rawQuery("SELECT 1 FROM users WHERE phone=?", new String[] { phone })) {
        return c.moveToFirst();
    }
}

为什么用 ? 占位符：可以防止把用户输入直接拼进 SQL，避免特殊字符破坏 SQL 语句，也更安全。

最终数据存储：注册成功后，账号数据进入 jntt.db 的 users 表；如果不是添加账号模式，还会把当前登录用户写入 SharedPreferences.pref_session.logged_user。

            "SELECT username FROM users WHERE username=? OR phone=?",

public User login(String usernameOrPhone, String password) {
    try (Cursor c = rdb().rawQuery(
            "SELECT username,password FROM users WHERE (username=? OR phone=?) AND password=?",
            new String[] { usernameOrPhone, usernameOrPhone, password })) {

public void addToCart(String username, Product product) {
    try (Cursor c = rdb().rawQuery(
            "SELECT quantity FROM cart WHERE username=? AND product_id=?",
            new String[] { username, String.valueOf(product.id) })) {
        if (c.moveToFirst()) {
            int qty = c.getInt(0) + 1;
            wdb().execSQL("UPDATE cart SET quantity=? WHERE username=? AND product_id=?",
                    new Object[] { qty, username, product.id });
        } else {
            ContentValues cv = new ContentValues();
            cv.put("username", username);
            cv.put("product_id", product.id);
            cv.put("name", product.name);
            cv.put("price", product.price);
            cv.put("quantity", 1);

        }
    }
}

    InputStream inputStream = context.getContentResolver().openInputStream(uri);

    Bitmap scaledBitmap = Bitmap.createScaledBitmap(bitmap, width, height, true);

二十四、实现差异与重要说明

1. 数据库与后端：需求分析文档中提到后端 Spring Boot、MySQL、RESTful API；当前项目实际没有后端接口，业务数据全部在本地 SQLite。

2. Android 版本：需求文档写 Android 8.0 以上，但 app/build.gradle.kts 当前 minSdk = 31，即 Android 12 以上。

3. 收藏实现：需求写收藏按钮；当前“我的收藏”实际复用文章点赞表 article_likes，没有独立 favorites 表。

4. 商品数量选择：需求写商品详情可选择购买数量；当前商品详情加入购物车一次只 +1，数量主要在购物车页面通过 +/- 调整。

5. 账号管理删除：需求写长按删除账号；当前代码实际只隐藏本机账号历史，不从 users 表删除账号。
